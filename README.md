# Simon Says Game

A fun and interactive memory-based game where players must remember and repeat an increasingly longer sequence of colors. Test your memory, concentration, and reflexes as you progress through different levels!

## Features

- Interactive gameplay with colorful buttons.
- Increasing difficulty with every level.
- Level and score tracking.
- Game Over detection for incorrect sequences.
- Restart option to play again.

## Technologies Used

- HTML5
- CSS
- JavaScript
- DOM Manipulation
- Event Handling

## How to Play

1. Press any key to start the game.
2. Watch carefully as one of the colored buttons flashes.
3. Remember the sequence of flashes.
4. Click the buttons in the same order.
5. Each correct round takes you to the next level.
6. The game ends if you click the wrong button.
7. Try again and beat your highest score!

## Getting Started

Follow these steps to run the project locally.

### 1. Clone the Repository

    git clone <your-repository-link>

### 2. Navigate to the Project Folder

    cd simon-says-game

### 3. Run the Game

Open the `index.html` file in your preferred web browser.
